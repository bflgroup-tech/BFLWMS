Store API Reference

Integration guide for stores pushing GRN and stocktake data into BFL WMS: authentication, request/response formats, and field-level detail for all three endpoints.

Overview Authentication Response format store/grn store/stocktake store/stocktake/report Error reference

1Overview

All endpoints live under a single versioned base URL and require a bearer token, obtained via an OAuth2 client-credentials exchange.

EnvironmentBase URL
Productionhttps://bflwms.bflgroup.ae/api/v1

The v1 path segment is a stable version marker — a future breaking change will ship as /api/v2 alongside it rather than altering this contract.

2Authentication

All three endpoints require a bearer token issued via the OAuth2 client-credentials grant. Contact your BFL integration contact to have a client_id / client_secret pair issued — there is no self-service signup.

Step 1 — request a token

Request 
POST /api/v1/oauth/token
Content-Type: application/x-www-form-urlencoded

grant_type=client_credentials&client_id=<your_client_id>&client_secret=<your_client_secret>
Response — 200 OK 
{
  "access_token": "eyJhbGciOiJIUzI1NiIs...",
  "token_type": "Bearer",
  "expires_in": 3600
}

Step 2 — call an endpoint

Send the token as a bearer header on every request:

Authorization: Bearer <access_token>
ⓘ Tokens expire after 60 minutes. Request a new one when yours expires — there is no refresh-token flow, just repeat Step 1.
⚠ Treat client_secret as a password. Store it server-side only; never embed it in a mobile app, POS terminal, or anything a store employee can inspect.

3Response format

Every endpoint below returns the same simple shape, regardless of outcome.

200Success 
{ "status": "success", "message": "..." }
400 / 500Failure 
{ "status": "failed", "message": "<reason>" }

400 means the request was rejected before anything was written (bad input, unknown store, duplicate record). 500 means an unexpected server-side error occurred. Always check status before treating a call as successful.

4store/grn

A store submits a GRN (goods receipt note): one header covering the whole receipt, plus one or more transfers, each carrying its own received item lines.

POST /api/v1/store/grn Bearer token required

Header fields

FieldTypeRequiredDescription
storeIdstringrequiredStore identifier. Must be a store already registered in WMS.
dateTimestring (ISO 8601)requiredGRN date/time.
ginNostringrequiredGIN number this GRN relates to.
userstringrequiredName/ID of the person performing the receipt.
transfersarrayrequired, min 1One or more transfers received in this GRN.

transfers[] fields

FieldTypeRequiredDescription
trfNostringrequiredTransfer number. Must not already exist for this store.
itemsarrayrequired, min 1Item lines received against this transfer.

transfers[].items[] fields

FieldTypeRequiredDescription
itemCodestringrequiredItem/SKU code.
eanstringoptionalEAN barcode.
epcstringoptionalRFID EPC value.
qrcodestringoptionalQR / serialized code.
trfQtyintegerrequiredQuantity as per the transfer.
scanQtyintegerrequiredQuantity actually scanned/received.

Example request

{
  "storeId": "BFL-SPRG",
  "dateTime": "2026-09-24T10:00:00",
  "ginNo": "GIN12345",
  "user": "user1",
  "transfers": [
    {
      "trfNo": "TRF001",
      "items": [
        {
          "itemCode": "ITM001",
          "ean": "1234567890123",
          "epc": "30340...",
          "qrcode": "BC001",
          "trfQty": 5,
          "scanQty": 5
        }
      ]
    }
  ]
}

Responses

200Success 
{ "status": "success", "message": "GRN created successfully" }
400Duplicate transfer 
{ "status": "failed", "message": "Transfer No 'TRF001' already exists." }

5store/stocktake

A store submits raw stocktake scan results: one header for the count session, plus the individual items scanned (EAN, QR code, RFID).

POST /api/v1/store/stocktake Bearer token required

Header fields

FieldTypeRequiredDescription
stockCountIdstringrequiredIdentifier for this stocktake session. Must not already exist.
storeIdstringrequiredStore identifier. Must be a store already registered in WMS.
trnDatestring (ISO 8601)requiredDate/time of the count.
usernamestringrequiredName/ID of the person who scanned.
itemsarrayrequired, min 1Scanned item lines.

items[] fields

FieldTypeRequiredDescription
itemCodestringrequiredItem/SKU code.
eanstringoptionalEAN barcode.
qrCodestringoptionalQR / serialized code.
rfidstringoptionalRFID tag value.
quantityintegerrequiredQuantity scanned for this line.

Example request

{
  "stockCountId": "SC0001",
  "storeId": "BFL-SPRG",
  "trnDate": "2026-09-24T10:00:00",
  "username": "user1",
  "items": [
    {
      "itemCode": "ITM001",
      "ean": "1234567890123",
      "qrCode": "BC001",
      "rfid": "30340...",
      "quantity": 1
    }
  ]
}

Responses

200Success 
{ "status": "success", "message": "Stocktake created successfully" }
400Duplicate count 
{ "status": "failed", "message": "StockCountID 'SC0001' already exists." }

6store/stocktake/report

A store submits the counted result of a stocktake: quantity counted, system SOH at the time, and the variance between them.

POST /api/v1/store/stocktake/report Bearer token required

Header fields

FieldTypeRequiredDescription
stockCountIdstringrequiredIdentifier for this stocktake session. Must not already exist.
storeIdstringrequiredStore identifier. Must be a store already registered in WMS.
trnDatestring (ISO 8601)requiredDate/time of the count.
itemsarrayrequired, min 1Counted item lines.

items[] fields

FieldTypeRequiredDescription
itemCodestringrequiredItem/SKU code.
eanstringoptionalEAN barcode.
quantityintegerrequiredQuantity counted.
sohintegerrequiredSystem stock-on-hand at count time.
varianceintegerrequiredDifference between counted quantity and SOH.

Example request

{
  "stockCountId": "SC0001",
  "storeId": "BFL-SPRG",
  "trnDate": "2026-09-24T10:00:00",
  "items": [
    {
      "itemCode": "ITM001",
      "ean": "1234567890123",
      "quantity": 5,
      "soh": 10,
      "variance": -5
    }
  ]
}

Responses

200Success 
{ "status": "success", "message": "Stocktake created successfully" }
400Duplicate count 
{ "status": "failed", "message": "StockCountID 'SC0001' already exists." }
